# Bootstrap web

Este repositório é a fonte pública e versionada do processo. Não contém credenciais, conteúdo publicado, IDs de conta, URLs de webhook privadas, nem dados de audiência.

## Recuperação

1. Abra `PROCESS_MANIFEST.json` no repositório ou pelo raw GitHub.
2. Leia `START_HERE.md`.
3. Leia a `SKILL.md` apontada pelo manifest.
4. Consulte as referências de capacidade e política de risco.
5. Rode o inventário somente leitura antes de qualquer operação.

Se a página GitHub estiver indisponível, use a URL raw declarada no manifest. Se a documentação Zernio mudou, atualize o snapshot com `scripts/update_docs_snapshot.py`, revise o diff e faça PR. Documentação externa nunca muda automaticamente o comportamento local.
